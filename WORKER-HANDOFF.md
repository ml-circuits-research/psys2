# Worker handoff

Read [AGENTS.md](AGENTS.md) and the current [worker-tasks.md](worker-tasks.md) before starting work.
The control session maintains the task list; the worker records progress in [worker-log.md](worker-log.md)
and raises questions in [questions.md](questions.md), following this repository's rules.

Fetch control updates regularly. Commit each completed task and push after the required checks,
so the control session can review the exact published commit.
