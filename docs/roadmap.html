Roadmap

Status: implemented planned (vision only) Fixture platform implemented; milestones 1 to 6 planned.

Specs: ADR-001, spec 06 Dialog, server, webchat

Vision: vision §16, vision §17

Purpose

Where the project is going and what exists now. The vision builds the complete architecture through dependency-aware milestones; automatic world construction, data ownership, versioning and the journal are present from the first integrated release, and early benchmark worlds are meant to come from the same skills as later ones (vision §16). ADR-001 amends this by adding rule-based formalization and hand-built fixture worlds so the platform can be built before C1 exists.

Implemented now

As described by the specs and AGENTS.md. Note: when these pages were written the src/ and worlds/ directories were still being populated by other work, so the status was taken from the specs, not from running code; run npm test for ground truth.

Modules can overlap where interfaces are stable. Each milestone yields executable infrastructure, retained experiments and a decision record. A failed experiment changes an implementation hypothesis through the contingencies below; it does not silently reduce the automation objective.

Vision and specs differ

Vision §16 restricts hand-built circuits to parser and interpreter fixtures and diagnostic baselines, and vision §1 says domain worlds come from C1 from the first integrated milestone. The current implementation (fixture worlds, rule formalizer, dialog, webchat) is built before milestone 1 under ADR-001; it does not satisfy milestone exits and is not claimed to.

Contingencies (vision §17)

Options to investigate only when measurements show a failure. The baseline stays encoder-based formalization, agent authoring and local GPU fine-tuning; generative formalization and an LLM fallback in C2 are excluded and would need a new architectural decision.

Research questions: how much task structure is shared across worlds, which scope distinctions need extra training, how to calibrate candidate readings, how to detect unsupported questions, how much independent evidence can be obtained automatically at acceptable cost. They are answered with ablations and learning curves.
