# Archived Map and Music interface fixtures

These source modules, vendor copies and licences belong to the former Map and Music demos. They are retained for historical fixture checks and are outside the published `docs/webchat` application.

The native editor composition in `scripts/lib/demo-composition.json` excludes these areas. `scripts/build-geo-data.mjs` updates the archived map data here; it does not add Map to the current demo.
