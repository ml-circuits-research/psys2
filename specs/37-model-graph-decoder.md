# Structural prediction decoder

`decodeModelGraphs` consumes a versioned `psys2.structural-predictions/1` packet. It does not run a reader or infer predictions. The packet identifies a structural graph model, supplies the original Unicode text, explicit whole-utterance coverage, and one or more alternative hypotheses. Each hypothesis contains predicted request spans, acts/moods, local target and constraint identities, selector/result phases, optional explicit logical closures, query projections and dependency edges. A missing structural model, truncation or unresolved decision cannot produce an executable candidate. An empty explicitly complete request list is a no-request prediction, not an invented request.

Local source/ownership wires are deterministic serialization metadata. A single selector constraint for an explicitly identified target supplies its selector edge; multiple selector predicates require an explicit predicted closure. There is no invented conjunction, target, goal, binder, context reference, correction or temporal order. Rootless flat result constraints retain the standard contract's implicit conjunction. Multiple requests retain separate namespaces and explicit dependency edges; they are never flattened into competing single-request readings.

Open semantic fields retain explicit token kinds and source evidence. Acts, target kinds/names, constraint concepts/values/relations and query concepts require supplied Unicode-scalar ranges, or a declared source identity plus those ranges. Structural closed decisions are model predictions and do not receive fabricated lexical spans. A field range must be inside its predicted request span. Repeated occurrences, quoted strings, references and numeric spellings are preserved; no token is reconstructed from a float or guessed from English text. Raw property descriptors without a canonical binding remain unresolved rather than being collapsed to a generic inventory concept.

Every alternative is preserved. Invalid or unresolved alternatives are retained in diagnostics and prevent complete coverage; the decoder does not silently choose a higher-scoring hypothesis. Whole-graph confidence is a separate explicitly calibrated record tied to a model/report identity. Auxiliary field scores are retained as auxiliary evidence and are never multiplied, averaged or relabelled as graph confidence. Structural validity is not semantic correctness or execution authorization: the application still requires its independent approved gate, native resolution and effect assessment.

The final gate is the published `serializeRequestGraph`, `inspectRequest` and `prepareRequestBatch` contracts. Unsupported turn/context representations are retained and refused until a published wire contract exists. This module contains no grammar, source-text pattern matching, evaluation gold lookup or model checkpoint claim.

Decoder coverage always reports `executable: false`, including when a trusted calibration record matches. Confidence identity is provenance, not a threshold or capability admission decision. A separate host gate must evaluate the approved threshold and scope; a zero-confidence graph cannot become executable merely by carrying a calibration hash. Declaration-derived open fields also require explicit source ranges in this profile; unanchored declaration defaults remain unsupported rather than receiving fabricated text evidence. The reserved local source identity `__model_source` cannot be supplied as another node identity; collisions refuse deterministically.
