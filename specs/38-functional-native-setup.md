# Functional evaluation setup

The functional replay first calls the published context seeder with evaluation-only native bindings. Diagram shapes are the entire declared native kind enum, not aliases inferred from a row's sentence. A Diagram creation has no label parameter, so preserving an annotated name requires its declared change operation after creation; both calls count. Calendar resources use declared creation, while meetings require supplied times, duration, participants and explicit room. Document creation requires supplied blocks. Drawing has no published lifecycle creation host and is reported unavailable. No arbitrary default, empty content or placeholder time is invented.

Every context attribute must be consumed. Unsupported names/kinds, invalid native identities, missing parameters, previous-turn context and policy failures are recorded. Partial setup retains its receipts and identities but excludes the entire row before reader invocation. Setup calls and observations are separate from application effects: unchanged-state comparison starts only after successful setup. Excluded rows remain in the denominator/table with their reasons and do not count as honest model replies. Empty contexts are valid without object creation. The sole SOP-BERT reader remains unchanged and refuses when no structural model is installed.
