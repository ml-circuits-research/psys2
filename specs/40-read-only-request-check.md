# Read-only native request checks

`checkRequest(world, request, options)` consumes a validated `mood=check` graph, copied historical observations, declared target plans and predicate bindings. It does not read text, call a model or invoke a native tool. The shared library evaluates the complete root or rootless conjunction, logical groups, negation/polarity and quantifier coverage with three-valued logic. No predicate content is unknown, never an automatic success.

Target plans identify an exact observation instance/scope/version and a declared semantic-kind to native-kind/type mapping. The shared resolveRequestTargets mechanism evaluates existing target descriptions against that complete native kind population. Each plan declares policy one or all explicitly; supplied plans cannot prefilter a bare kind with additional predicates. Selector graphs use the same equality callback as result predicates and never borrow result requirements to choose an object. Named targets require an explicit nameBinding identifying the native property, exact name wire tokens, resolved native tokens and a mapping witness; there is no label/title/name guessing. Determiners require an explicit matching determiner-token/policy declaration. Missing description bindings remain unknown. A unique complete selection grounds a singular target; quantification retains the selected population and completeness certificate. Native identities and incarnations remain correlated with the supplied historical snapshot.

Predicate bindings identify the constraint's concept and exact wire value tokens, the native property declaration and resolved expected canonical tokens plus a mapping witness. Those mappings are trusted authored semantic declarations, not model truth predictions. Only equality is currently evaluated, through the existing public projection guard in native selection. Unknown operators or additional semantic fields remain unknown. Input source/type/version/key and dimension/unit/frame must match the declared binding; missing values and incompatible evidence are unknown rather than false. Tokens are compared exactly, so quoted strings and bare symbols differ. Logical negation applies only in the shared graph evaluator.

The result retains mapping/selection evidence and is always non-executable. It is not an immutable assessed reply claim or an assertion about current live state. Input copying has an independent maxBytes cap (default and maximum 4,000,000). The budget is a conservative reservation ledger, not an exact consumed-step count. Before each subordinate call, the adapter reserves its entire granted ceiling; native selection reserves twice its grant for its traversal plus projection evaluator, and the target resolver and graph walker each reserve their own disjoint ceilings. Callback work uses only the unreserved remainder. subBudget defaults to 1,024 per leaf/selection component. Repeated leaves cannot reuse a previously allocated allowance. Any exhausted grant or ledger invalidates the entire check as unknown, including where another logical branch might otherwise decide truth. Results expose charged reservations and the limit. The application remains SOP-BERT-only with no graph checkpoint or newly installed check route.

This landing adopts published library 0.200.0 at 6cce066, sharing one application/training codec bundle. The codec's unchanged std.request@0.198.0 label contract remains valid because this release adds graph evaluation and target resolution, not a wire-schema change.
