# Raw structural prediction bridge

`bridgeRawStructure` accepts `psys2.raw-structural-predictions/1`: original Unicode source, known area, actual structural model identity, explicit coverage, predicted requestCount and raw v2-shaped predicted requests. UNKNOWN is an unresolved diagnostic, not absence; overflow keeps an explicit count diagnostic and cannot produce a complete graph. Optional absent fields stay absent. The runtime never receives annotation rows, gold requests, fixed field queries or a grammar parse.

The predictor may supply `ranges:[{path:['requests','0','span'],range:[start,end]}]`, including nested predicted span fields. Coordinates are Unicode scalar offsets into the original source. Each supplied span string must equal that exact source slice, and child ranges must lie within the predicted request. Ranges can disambiguate repeated substrings; without them, only an exact unique occurrence of the supplied predicted substring may anchor it. This is source alignment, not phrase recognition. Invalid/unconsumed pointers remain unresolved; no pointer is clamped.

Canonical lookup uses a frozen `sop.structural-bindings/1` table and its declared SHA256. Every matched kind/property/unit record must carry canonical identity, source wire/world/module version and source snapshot SHA. A lookup must be unique. Property identity uses the full raw area/key descriptor, never a generic inventory concept alone. The caller authenticates the frozen table/hash; the bridge retains provenance but does not claim to cryptographically authenticate an arbitrary supplied object. Ambiguous/missing bindings remain unresolved. Unknown raw keys are retained and refused rather than discarded.

Ownership IDs and selector/result partitions are mechanical. A frozen annotation-policy declaration licenses unmarked AND, with its exact prompt hash; standard explicit bound quantifiers preserve collection/binder/body. Request dependencies, relative operators without reference projection, query-content conversion, context/turn references, arbitrary groups and unsupported population references remain unresolved. Raw predictions remain available beside typed projections and diagnostics. Generated toy fixtures run both the C1 Python projector and runtime bridge and compare supported typed structures exactly; no evaluation sentence bank is used.

The bridge passes its result to the existing typed graph decoder for serialization and inspection. Decoder work has an independent explicit budget; bridge traversal and bounded data copying have their own limits. It never creates graph confidence from head scores, never sets executable=true and never invokes an effect. A structurally valid candidate is not a trained-model accuracy result. Actual checkpoint inference, calibration and admission remain separate steps.


Direct value representation requires exact identity between the predicted source literal and predicted value. A red value anchored to blue refuses even when the property's valueKind is string. If value_span is absent, the value itself must have a unique source occurrence; a supplied empty or incompatible span is not discarded. Nonidentity values require one exact source-backed `valueNormalizations` table row with area, full raw key, canonical property, source literal, value, valueKind and the same complete declaration provenance as other bindings. Its sourceWire is retained as the value's declaration evidence. For example a declared number source may authorize two → 2; the bridge never invents a number parser, trims text or maps arbitrary phrases. Duplicate or missing normalization records remain unresolved. This normalization table is trusted frozen host data, not a predicted proof or gold annotation.

Explicit source-copy predictions may provide a `ranges` entry at `requests/<index>/constraints/<index>/value`. This is a Unicode-scalar pointer to the exact emitted value, not a normalized interpretation. It must lie inside both the original `value_span` (when supplied) and the request span. The original wider evidence remains the constraint source; the narrower copy becomes value evidence. Wrong text, missing/invalid wider evidence, outside-parent ranges and unused paths refuse. Without an explicit copy pointer, existing identity or source-backed normalization rules remain unchanged. Internal neural value-mode and copy-span heads are not RAW fields and must be consumed by a versioned model adapter.
