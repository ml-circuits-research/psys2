# Frozen source-only BIO cutter prediction

`training/sop-bert/predict-request-cutter.py` loads only a completed, explicitly hashed cutter run. It requires checkpoint/config/final-verification/trainer hashes, verifies the complete trained-cutter role, strict checkpoint configuration/state, codec and every recorded encoder file. It refuses an active run without final verification. Input records contain exactly `id` and `text`, with no area/context, request annotations, gold spans or field queries.

The predictor uses the actual source-only fast tokenizer and the frozen trainer's BIO decoder. Exact scalar offsets and source sequence identities are passed through unchanged; logit ties become unknown labels, illegal I-after-O and truncation refuse globally. Special/padding tokens are ignored only by the documented codec. There is no repair, normalization heuristic or semantic parsing. Exact codec format `sop.request-cutter-codec/1` maps explicitly to the runtime envelope's integer decoder version 1; its full codec hash remains present. All-O is a valid empty cut proposal, not proof that the source contains no request.

Checkpoint, config, final verification, trainer, predictor, input and encoder files are fingerprinted before and after inference. A changed file prevents a complete output manifest. Output creation is exclusive; incomplete output without a complete manifest is not a frozen result. CPU FP32 or CUDA BF16 is recorded explicitly. The predictor does not compute whole-graph confidence or activate the application. Pure generated fixtures verify normalization; actual model evaluation requires the final frozen training handoff and separately coordinated compute ownership.

The broader application boundary remains unfinished: accurate create/remove/check/logical proposals are not automatically executed by the narrow property-change coordinator. Declared host operations and batch tools exist, but general capability projections and full semantic-field consumption still need explicit integration. This predictor does not conceal that execution limitation.
