# Frozen per-request key-reader prediction

`training/sop-bert/predict-key-reader.py` prepares source-only inference for the published `sop.key-reader/1` architecture. It does not install an application provider, train a model, or certify semantic execution. Actual checkpoint inference must wait for a completed run and its frozen hashes.

The CLI accepts JSONL records containing exactly `id`, `text`, `area`, and `context`. Text is the exact request substring. Area and context are supplied by the host observation boundary, never teacher annotations, gold mention ranges, requested field queries, or expected outcomes. The input file is hashed; duplicate IDs and additional fields refuse the run. The tokenizer uses the same sorted JSON context pair, longest-first truncation, and maximum length as training. A truncated source or context makes coverage incomplete.

The configuration determines all key orders, BIO streams, typed banks and per-mention metadata heads. Strict greedy BIO decoding uses only source sequence tokens, rejects tied/nonfinite labels and orphan I, and retains distinct mentions of the same key. Metadata is computed on each **predicted** mention's mean hidden representation plus its declared key embedding. Context tokens never become copied source evidence. Global closed classes use the request CLS representation. Presence sign is an uncalibrated binary decision; inconsistent presence/class/span decisions remain unresolved.

The raw packet contains a request, explicit Unicode-scalar relative ranges, source snapshot, unresolved diagnostics and a checkpoint/tokenizer/codec identity tuple. Open values are copied exactly. A closed normalized value differing from its copied span requires a later declared source proof; the predictor never invents a normalizer. Literal sentinel-looking strings remain values because bank states, rather than string spellings, identify absence and unknown. No probability product or average is presented as graph confidence.

The frozen model has no independent target-type head. Every packet currently carries `target-type-requires-declared-kind-route`; target type is not inferred from the first property, area, or an English word. Measure/unit metadata without model heads, unsupported global routes, unknown classes and unrepresented normalization remain explicit. Consequently this initial predictor cannot advertise complete executable graphs. The separate bridge may consume a future verified unique declaration-backed route, but that route is not implemented here.

Before loading, the CLI verifies checkpoint, config, final run record, trainer and preparer/codec-source hashes. The final record must bind the same checkpoint/config/trainer, have positive training steps, and match the exact trainer in the config. Every recorded local encoder/tokenizer file is verified; strict state loading and embedded checkpoint config equality prevent architecture substitution. The codec identity includes the predictor bytes and exact preparer GLOBAL/META field mappings. All artifacts, encoder files and input are hashed again after inference. A changed file prevents a complete output manifest; an interrupted output remains provisional. Model/context provenance is a trusted host input boundary, not a proof that arbitrary caller-supplied context is true.

CPU fixtures cover repeated-key distinct phases, source/context separation, scalar offsets, malformed/tied BIO, unknown metadata and source-proof refusal. No GPU work, checkpoint export, current training mutation, application activation or quality claim is part of this preparation.

The supplied preparation manifest is part of the frozen identity chain: its bytes must match `config.dataManifestSha256`, its `scriptSha256` must match the supplied preparer, and rebuilding the trainer configuration from its registry must reproduce every trained layout field. The manifest supplies metadata only; annotation rows are never loaded by inference. Coverage also includes an inventory-wide static support table distinguishing masked/untrained derived heads, learned presence with an unsupported value decoder, declared class heads and source-copy routes. A negative learned measure/unit presence remains a learned absence decision, not a claim that a value decoder exists. Copied numeric globals retain their source span but omit the typed numeric field pending declared conversion.
