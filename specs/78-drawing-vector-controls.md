# Drawing native controls and actual vector constituents

The Drawing editor fills its desktop pane and uses a responsive side inspector. Creation choices are read from actual native tool declarations; named colours are read from the existing colour knowledge. Pointer, mouse, trackpad and keyboard actions call the same typed native tool door as other controls. Drag previews affect transient renderer geometry only; release issues one declared placement or affine transform. Object identity survives label edits. Selection/deselection are explicit ask operations. Label, size, colour, delete, clear, undo and redo remain real native transactions; exports use the actual SVG/PNG renderer directly.

Compound drawings already consist of vector constituents. The host now observes them separately under `art.draw.part`, with namespaced ids, parent reference, role, primitive, colour, position/size and explicit origin. An observed constituent of a particular house is not an assertion about every house. The inspector exposes these actual parts; part colour, placement, resize, deletion and extraction use generic geometric operations. Editing an instance stores self-contained constituent geometry while retaining its semantic source kind. No operation branches on a house, roof, person or other sentence/domain example.

The operations reuse `scene.partsOf`, `piecesOf`, `groupOf` and `registerShape`. A group retains its actual member objects and reference frame. Ungrouping restores them with the group's translation, scale, rotation and reflection applied. Taking apart a knowledge compound yields its named geometric constituents. No bitmap or screenshot replaces the vector structure. Geometry snapshots participate in the existing native history and can be undone.

The word search reads the published vocabulary for objects, people and scenes, rather than presenting a hand-written list. Vocabulary membership alone does not promise a drawing. `drawing.catalog.make` declares its `name` as a `knowledgeInputs` lookup. The worker loads the actual knowledge entry before native execution; the synchronous primitive reads only that loaded entry and requires actual constituent geometry. The browser supplies a name, never unverified geometry/provenance. Missing renderable geometry is reported as unavailable. Source meaning and borrowed realization remain separate in the instance origin.

Tests: `tests/drawing-ui-declared-host.test.mjs` covers identity-preserving selection/movement, stale/refused atomicity, native page-clear undo, individual part modification, extraction/group/ungroup with transformed constituents, actual loaded catalogue geometry and rejection of UI-supplied parts. Existing lifecycle tests now distinguish root objects from the additional observed child parts. Browser layout, mouse gestures and the published knowledge lookup are checked in the integrated browser run.

The default gesture is selection: click/touch selects, Ctrl-click or Command-click toggles membership, and dragging empty space selects a rectangle. The toolbar has one Add button; it opens a small chooser of declared shapes and the knowledge word search. Double-clicking empty canvas opens that chooser at the indicated point. Choosing creates and selects one actual object and closes the chooser. Creation does not leave an add mode active. Delete appears in the contextual inspector and is also available from the Delete key. Undo, redo, clear and exports stay global.

The contextual inspector shows an immutable read-only ObjectID and a separate optional Label. Label is a native `label` property rendered below the actual object in canvas, PNG and SVG. Older `name` values remain readable when no label property exists; an explicit empty label suppresses that compatibility display. Identify IDs briefly overlays the actual native IDs; Show IDs keeps that overlay active and persists its preference when persistence is enabled.

Selection bounds have eight resize handles. `drawing.objects.transform` accepts exact selected IDs and the destination rectangle (`x`, `y`, `width`, `height` in canvas pixels). It composes an affine transform in native state, preserving relative member positions and supporting nonuniform scaling of rotated geometry. One pointer release makes one undoable native transaction. The same operation moves a multiple selection without collapsing its members to one location. Object and constituent rendering, extraction and grouping consume the native affine geometry.

New groups expose their preserved child ObjectIDs as actual `members` SOP references; child objects have an `in` reference to their group. Constituent edits synchronize preserved child geometry, so ungrouping retains those edits and identities. New grouped projections opt into this through `shape.nativeMembers`. Older groups keep their exact previous observation until edited or regrouped. Optional observed label/width/height fields appear only when the native projection owns those keys. The fixture `tests/fixtures/drawing-native-3ce76683.sop` was generated with the actual published 3ce76683 Drawing modules and must restore through the strict archive loader. Affine geometry, member references, persistence and rendered label tests are in `tests/drawing-transform-declared-host.test.mjs`.

Native member IDs remain directly addressable while grouped. Selection, label/colour/size changes, placement, affine transforms, constituent operations, deletion and ungroup resolve recursively through the declared group model. A member edit rebuilds its ancestors from the same native members in canvas coordinates, preserving unaffected siblings, actual IDs and vector geometry. The contextual Group member control selects those actual IDs and can return to the parent. A selection containing an ancestor and its descendant is rejected as an overlapping target set.

Recursive native operations tick the shared computation budget and cap group traversal depth at 32; exhaustion refuses the staged transaction atomically. Explicit member colour changes preserve the group's own colour and unaffected siblings; a later whole-group recolour applies through the native members again. Declarations name containment ancestor bound updates (`in`/`parent`, position and dimensions) for verification; those derived changes remain unverified rather than being mistaken for unrelated peer mutations.

Identify IDs and Show IDs also use declared native commands: `drawing.ids.show` takes `mode=temporary|always|off` and optional integer `duration` (default 4000 ms, range 1–60000). It stores optional `idDisplay={mode,expiresAt?}` in the instance; temporary expiry is an actual timestamp. Only projections that own `idDisplay` expose the `drawing.page` page fact and its mode/expiry, preserving old archives. These view navigation commands enter the same compact intent journal but do not add a picture undo step or dice samples. The renderer and checkbox read actual instance state. New Drawing dice make/change declarations generate visible `label` changes; legacy `name` remains accepted for compatibility.
