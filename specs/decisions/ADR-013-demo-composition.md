# ADR-013 — Explicit demo composition; Map and Music retired

Status: implemented for Map and Music. Charts remains a separate area until it is integrated into Diagram; Avatar remains a popup until it is integrated into Drawing. The calendar host foundation is not yet an active conversational area.

The owner removed Map and Music from the demo. The application is now selected by the explicit world list in `scripts/lib/demo-composition.json`. Directory presence is not application membership. The browser build and shipped Node replay use `createDemoLoader`, which restricts listing, file access and module loading, rejects missing selections and declared imports/reads/compose dependencies outside the selection, and regenerates shell/help knowledge and routing cards from that selection. Browser bundles, word/action indexes and tab/effect metadata therefore agree about available worlds. The UI's ordering and busy-view list no longer name retired areas.

This is application retirement, not deletion of source fixtures. Map/Music world sources, renderers and vendored assets remain available in the repository for existing generic infrastructure tests. They are absent from the demo's world bundles and active plugin metadata; the demo never registers their renderers or effects. The generic filesystem loader remains a full fixture loader. Build tests assert the absence of retired bundles, routing targets and metadata. Lazy-load/reload tests exercise surviving tools instead of removing their coverage. The existing system-map document inventories source fixtures, not this active application selection.

Historical session rows remain unchanged. Replay maps a retired tab to Talk. The ledger hygiene classifier recognizes a retired tab or explicit retired world identity, but this landing does not rewrite the historical set or retire additional evaluation rows; their existing checks still run. Review can decide any later explicit scope annotation from the reported per-row results. A general mention of music or a map does not itself exclude a row: such words can still occur in knowledge or drawing requests. Measurements must report scope and verdict changes explicitly; a reduced judged denominator is not an implementation win. No language pattern, acceptance sentence or model-specific patch is introduced to compensate for retirement.

## Availability messages and fixed-cohort reporting

The composition also declares retired area identities, world identities and display labels as data. An explicit host `send` option `view` selecting such an area produces a terminal unsupported reply with the composition's label and an `unavailableArea` evidence record. It performs no tool action and leaves state/history unchanged. This is not word matching: “write about music” in Documents or “draw a map” in Drawing uses the ordinary reader. Recognition of an unavailable area from unrestricted natural language is not added by this boundary. The browser worker receives the same declarations in its world index; a stale saved tab or URL fragment shows the corresponding availability notice on startup rather than silently implying that the old area remains present.

Replay supplies the historical tab as an explicit selector only for declared retired areas. An evidenced refusal with no state change or effect is classified `honest`; the old content check still runs and its verdict is retained as `historicalVerdict`. The overall judged denominator remains unchanged. Reporting adds disjoint surviving-area and retired-area views, including every retired-area row and its historical verdict. This is separate from old records already marked `retired`, which remain skipped exactly as before. The active-area failure list excludes retired capabilities but their results remain visible in their own table. Comparisons apply the same declared area partition to both snapshots, never just to the newer result.

The audited set has 41 turns in Map/Music (12/29), seven of them judged. Only seven rows changed verdict in the initial retirement landing; that is not the count of all retired-area turns. The surviving judged cohort before and after that landing was 124/200; the overall denominator was 207. These distinct quantities must not be reported as an unchanged 131/207 or as seven total retired turns. Final current measurements are recorded with each landing.
