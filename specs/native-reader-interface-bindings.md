# Literal native reader interface bindings

The C1 native binding exporter declares each raw annotation family explicitly against an actual host `on` type. Exact parameter names join only within that declared family. Source descriptions, example sentences and spelling similarity do not supply these identities.

Generated SOP schemas contain family types and scalar property slots, including actual parameter enums. Each binding references its exact schema text hash and the actual adapter source. These are native interface identities, not global knowledge concepts. Structured arguments and semantic transformations remain separate work.

The overlay preserves existing semantic family/property bindings. Its `readerAreaByView` explicitly activates the new Avatar reader area; metadata without this declaration retains the prior context area. Context projection can select a family by actual observed source type when no lexical kind is supplied. Abstract families never become names to look up in an object catalogue.

Gold request integration checks demonstrate actual Avatar composition and Drawing label changes through this mechanism. They do not measure neural prediction accuracy or certify all editor operations.
