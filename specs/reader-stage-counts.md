# Compact actual reader stage measurements

`reader-stage-replay.mjs SPEC OUTPUT_PREFIX` uses the existing actual Node reader host and exact immutable q8 artifact spec. It recreates the functional replay's native state, declared fixture policy and seeding for every matrix row, then compares the ordered eligible IDs against the published browser report (exactly301). A changed source hash/cohort refuses before model measurement. Only source text and actual seeded native context enter inference; annotations are never model inputs. This is a Node CPU measurement, not browser numerical parity or full calibration.

One compact JSONL record is written per eligible row with source ID/hash, area/classes, cutter span positions/count/status, request head capability/class-state/emission, repeated constraint-key counts and required metadata presence, raw availability/completion, final pipeline coverage/candidate count, and layered refusal paths. No source values, full tensors, logits or copied raw annotation answers are written. Missing stages are null, not zero. Complete empty reading is separate from nonempty graph proposal. Pipeline coverage is not proof the decoder ran: raw construction marks the bridge call boundary in this exact pipeline, while separate decoder reach remains unknown except a successful nonempty graph. Failed stages are not silently classified as decoder refusals.

Reasons retain source stage/path/key and propagated underlying detail. Rankings report distinct rows and occurrences, with overlapping row denominators. Underlying rankings prefer direct component issues and exclude generic wrapper-only reasons; propagated leaf details supply missing direct diagnostics without doubling them. Requested mood/act/type/mode/fill and operator/phase/polarity/character heads exist in the frozen model; predicted absent/unknown is distinguished from missing capability.

Output is streamed and capped16MB;48MiB free space is required before output and checked every25 rows, preserving a32MiB operating margin. Existing per-turn diagnostic memory cap remains16MB and tensors are not persisted. Final source/spec hashes are rechecked. The script never installs admission, changes an app artifact, modifies a checkpoint or supplies semantic correctness labels. Tooling fixtures cover unknown vs zero, class absence vs capability, repeated keys, propagated issues and prebridge failure; actual301 measurement follows the frozen tested tooling publication.
