# Source-conditioned raw structural model

`training/sop-bert/train-structural.py` trains over every clean C1 teacher record, using original raw annotations as supervision even when canonical bindings are unresolved. The model receives only source text paired with actual supplied area/context JSON, recursively sorted keys, Unicode preserved and compact separators. Annotation requests, field identities, gold counts and candidate values never enter the encoder input. Context must come from available input/world state, not expected request annotations.

The clean auxiliary model supplies encoder initialization only. Learned request-slot queries cross-attend to encoder tokens; learned constraint-slot queries attend using request features. Heads predict request presence/count, request/trigger ranges, target fields, constraint count and raw key/value/operator/phase/polarity/character/scope/group/step/unit/measure/anchor fields, plus question/turn fields. Requests/constraints beyond the training-derived slot capacities use explicit overflow, never clipping. C1 local IDs and containment are metadata, not arbitrary model labels.

Categorical banks use typed entries: index0 absent, index1 unknown, subsequent entries hold actual JSON values. Explicit null and literal strings such as `<ABSENT>`, `<UNKNOWN>` or `null` remain real values distinct from absence and unknown. Banks are built only from training rows. Unseen calibration labels are unknown and cannot count as correct values. Open names/literals also have learned source-span pointers, so the interface is not only a closed training-value enum; unknown normalized values remain explicit rather than selecting a nearest label. Declared binding/copy normalization is a separate stage.

Span heads predict absent/present/unresolved and token start/end for source sequence zero. Gold literal anchors must match uniquely within their annotated request and align exactly to tokenizer boundaries; otherwise pointer loss is masked and unresolved is recorded, not a negative label. Source and context token truncation are counted independently; either makes that row unsupported for full raw exactness while retaining the row. Inference must likewise declare incomplete coverage. Unicode scalar ranges are the external contract; tokenizer indices are not user ranges.

V1 flattened answers do not become invented target/constraint graphs: they supervise count, presence and explicit request/trigger spans. V2 provides broad nested raw fields and spans. Conditional head accuracy is labelled conditional on annotated slot support; unseen labels and overflow cannot inflate correctness. V2 raw-tensor exactness is a conservative representation-level lower bound, not canonical graph accuracy or calibrated confidence. Canonical bindings, reference/semantic normalization and published graph validation remain separate, and the model never obtains whole-graph confidence by averaging head scores.

The manifest freezes source/data/exclusion/script/encoder-init/config hashes and preprocessing diagnostics. Training independently checks all source hashes, split identities and excluded IDs before bank construction. Compact checkpoints contain model weights/config only, not optimizer continuation. Preflight reserves twice model bytes plus128MiB; each atomic save checks model bytes plus64MiB. Compatibility smoke can explicitly disable weight saves. Frozen full auxiliary model, raw/generated source data and completed exports are preserved.

Actual runtime target is `psys2.raw-structural-predictions/1`, with raw v2-shaped predicted fields, exact scalar ranges and explicit unknown/overflow diagnostics. A declaration-only bridge produces the closed canonical decoder packet. No grammar or sentence-pattern runtime is introduced. This trainer/first checkpoint alone does not activate a reader or establish full request confidence.

## Frozen v1 baseline limitations

The v1 normalized value bank is a train-observed enum, not a general open-value output mechanism. Pointer heads exist, but learned copy-versus-declared-symbol mode is not yet implemented. Its frozen calibration therefore establishes no correct complete command: all16 exact V2 rows are empty requests (16/17 empty;0/1,681 nonempty). Target-count field's high aggregate accuracy is entirely absence:0/39 present values,1,961/1,961 absent. The independent frozen evaluator reports these buckets and unseen support rather than presenting aggregate accuracy as competence. A new v2 file/objective will preserve this baseline and add explicit value modes/source copy and declared normalization, with unknown retained.
