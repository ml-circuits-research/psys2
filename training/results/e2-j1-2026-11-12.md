# E2 gate for J1 (sopworld 0.13.1): the host's `lacks` zeroing is dropped (2026-11-12)

`ReasonerSession.score` no longer replaces the `lacks` measure of the library's ranking (a question reading counted as lacking nothing); the order is the library's `rank(results)`. Same sets as `e2-default-veto-2026-11-12.md` (8,637 messages now: operational, operational-ro, dialogues, gold, loose, typos, real, mobile), rules mode, collected with `scripts/e1-collect.mjs --mode rules --world-aware <mode>` on the tree before (commit 2449af3) and after the change, case by case.

| mode | before (right / partly / not understood / wrong) | after | moves |
| --- | --- | --- | --- |
| veto (the default) | 7266 / 87 / 757 / 414 | 7266 / 87 / 757 / 414 | none: every case identical, 0 new wrong |
| choose | 7272 / 84 / 756 / 412 | 7273 / 84 / 755 / 412 | 1 not understood to right, 1 wrong to right, **1 right to wrong** |

`veto` does not use the order (it vetoes a reading, it does not rank readings), so it cannot move: the default gate holds, 0 new wrong. `choose` (not a default, opt-in) has one new wrong:

- `loose-words` docs.reader#L553, "gretel say what" (the best-effort reader, tab Documents). Before: the best-effort candidates "what did gretel say" / "tell me what did gretel say" were picked; after: the rules reading `kids.animals:pat.kids.animals.x.sound.d` (a question, "what sound does gretel make") is judged by the library and **lacks `sound`** (a lack the zeroing hid), and the library's order puts the unjudged statement reading `kids.animals:pat.kids.animals.ts` ("a gretel goes what", lacks nothing) first, so the reply is "OK, a gretel goes what." instead of the quote. The library is consistent here (the sound of a "gretel" is not known: a real lack); the zeroing had made the question win by a criterion that is not the library's. Not fixed in the host, because the fix belongs in the criteria of the rank (an unjudged statement that tells a new nonsense animal should not beat a question whose only lack is a missing fact): library item.

The same run had the same count of judged readings (3,135 of 7,922 segments in `veto`; 3,124 / 3,125 in `choose`).
