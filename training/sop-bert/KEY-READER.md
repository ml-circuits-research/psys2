# Inventory-key reader preparation

`prepare-key-reader.py` expands every retained request (plus empty-message negatives) from the frozen structural teacher corpus. It verifies both input file hashes and retains each original request. Version-one unknown metadata is masked; version-two ownership and phase remain per condition. Same-key overlapping intervals remain in the record with diagnostics and masked BIO supervision.

`train-key-reader.py` is a conditional gold-request-cut learner. Its independent global/domain BIO streams permit different keys to overlap and a key to occur repeatedly. Schema-declared class banks have typed absent/unknown controls; arbitrary observed literal strings are never a class vocabulary. Domain closed values and metadata use each mention's pooled representation plus its key embedding. Class losses average within each head and then across heads. Presence losses balance positive and absent strata within each inventory key. BIO streams use train-derived class weights.

The first CUDA smoke used eight training/eight calibration records and four updates without saving weights. It verifies finite losses and shape compatibility, not reader quality. Unsupported normalizations and candidate identities remain unresolved. Missing/ambiguous anchors mask BIO supervision. A full run requires per-key calibration, predicted-mention metrics, checkpoint provenance and best-checkpoint retention; no full run or executable graph model is claimed by this preparation increment. Runtime must consume predicted cutter intervals and predicted BIO mentions, never annotation spans, counts or field queries.

The follow-up adds per-key presence TP/FP/FN/TN, decoded mention TP/FP/FN and invalid BIO counts, positive/absent token denominators, global class present/absent/unknown counts, and explicitly gold-mention-conditioned metadata class counts. BIO/global subset exact is not full raw request exact. Best checkpoint selection uses decoded conditional mention F1; the run records source encoder file hashes and initialization checkpoint identity. Source/context truncation masks BIO and prevents exact credit. Final immutable raw structure and canonical graph evaluation remain separate obligations.
